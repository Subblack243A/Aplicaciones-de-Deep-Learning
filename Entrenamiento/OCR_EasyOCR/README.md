# Entrenamiento OCR - EasyOCR/PyTorch

Este directorio contendrá el código para entrenar o ajustar un modelo OCR (Optical Character Recognition) basado en o equivalente al utilizado por el proyecto de Kinect.

Dado que del Kinect se extrae una imagen con las líneas trazadas en el aire y de allí se infiere el texto, este directorio está preparado para albergar el código fuente del entrenamiento y preparación de ese modelo OCR.

## Próximos Pasos

- Añadir el dataset de imágenes de trazados.
- Añadir el modelo de extracción de características (e.g. CRNN).
- Añadir el script de entrenamiento principal.
